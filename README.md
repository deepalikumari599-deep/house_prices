🏡 House Price Prediction

A Machine Learning web application that predicts house prices based on property details such as carpet area, bathrooms, balcony, floor number, total floors, location, furnishing, transaction type, ownership, facing, and overlooking.

The project uses **Python, Scikit-learn, Pandas, Joblib, and Streamlit**.

---

✨ Features

- 🏠 House price prediction
- 📐 Carpet area input
- 🚿 Bathroom selection
- 🌿 Balcony selection
- 🏢 Floor number
- 🏙️ Total floors
- 📍 Multiple locations
- 🛋️ Furnishing type
- 💳 Transaction type
- 📄 Ownership type
- 🧭 Property facing
- 🌳 Overlooking option
- 🎨 Beautiful Streamlit user interface
- 🌤️ House illustration with sky, trees, plants and fairy lights
- 🤖 Machine Learning prediction model

---

🛠️ Technologies Used

- Python
